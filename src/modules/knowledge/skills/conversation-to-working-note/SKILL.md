# Conversation to working note

Read the source note completely, prefer an existing working note, identify the
processing subject, and apply the configured schema and template. Record source
material, group core ideas, compare patterns or tensions, formulate a provisional
synthesis, and list possible insights and open questions. A working note may stay
exploratory; do not force a durable claim.
