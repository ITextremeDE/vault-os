# Conversation capture

Use when a concrete exchange should become source material for later processing.
Do not use for irrelevant exchanges, an existing note that should be extended,
or a result already distilled into a durable claim.

1. Decide whether a standalone note is warranted.
2. Identify the main topic and verified source context.
3. Apply the configured timestamped filename, schema, and template.
4. Summarize occasion, relevant content, key points, and next steps.
5. Preserve uncertainty and do not invent details.
6. Write only within the authorized scope and record the content change.

The output is concise source material, not a transcript, working note, or insight.
