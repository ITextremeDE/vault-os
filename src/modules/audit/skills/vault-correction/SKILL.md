# Vault correction

Require explicit vault-audit finding IDs and any material variant choice. Split
each selected finding into OS and content work. Correct OS causes first, validate,
then reassess which content symptoms remain and correct only those still present.
Validate again after each block.

Do not run parallel broad rewrites, change content on an unstable rule base, or
expand beyond selected findings. Report authorization, ordering, OS changes,
content changes, findings made unnecessary by cause removal, and remaining work.
