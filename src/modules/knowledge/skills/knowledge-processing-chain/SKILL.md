# Knowledge processing chain

Default path: conversation → conversation note → working note → insight.

Use only the smallest useful stage. A conversation note preserves the exchange;
a working note analyzes it; an insight preserves one durable claim. For already
distilled research or answers, update the natural canonical note directly when
authorized. Do not create intermediate files by habit, duplicate existing notes,
or preserve short-lived replies and unsupported guesses as knowledge.
