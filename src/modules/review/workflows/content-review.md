# Content review

Review content notes for metadata, classification, destination, naming, clarity,
sources, contradictions, possible obsolescence, links, and lifecycle state. The
review view is a work surface, not a rule source.

1. Read the complete note.
2. Validate required fields and registered values.
3. Check filename, destination, and duplication.
4. Evaluate clarity, evidence, unresolved contradictions, and useful links.
5. Assess status, completion, and archive readiness.
6. Apply only the smallest authorized correction and record material changes.
7. Set `reviewed` only after the review actually occurred.

Do not delete, invent schema values, reinterpret content, or reorganize broadly
during a review without explicit authorization.
