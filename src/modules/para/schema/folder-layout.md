# PARA folder layout

The PARA module provides logical roots for inbox, projects, areas, resources,
archive, and journal content. Concrete folder names and language belong to
instance configuration; consumers must not infer them from this document.

Use numbered top-level folders only when the instance selects that convention.
Keep the system root separate from content roots, and route uncertain material
to the configured inbox until its natural destination is clear.
