# Filing

For new or revised information, decide in this order:

1. New independent content or an addition to an existing note?
2. Which configured content kind and type apply?
3. Is an area required, and is its value registered?
4. Which configured content root, template, and filename rule apply?

Prefer an existing canonical note when it is the natural semantic home. Create
a file only for an independent, reusable unit. Route unclear material to the
configured inbox. Before writing, validate metadata, destination, filename,
and whether the instance change log requires an entry.

When an agent conversation is the direct source, record its verified identifier
or source reference. Never invent an identifier from a filename.
