# 03 Workflows

Workflows describe how people, agents, and automation apply system rules in
daily operation.

The core defines the workflow contract but requires no particular productivity
or knowledge method. Optional modules may add capture, organization, review,
journal, contact, knowledge, or archival workflows.

A workflow may depend on declared schemas and registers. It must not silently
create new fields, values, ownership rules, or competing standards.
