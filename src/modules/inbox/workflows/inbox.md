# Inbox

The configured inbox is a temporary capture area for material whose destination
is not yet reliable. Clear material does not need an inbox detour.

For each item, identify its subject, search for a natural existing note, choose
a configured kind and type, validate any area, and decide whether a new file is
necessary. Then file, merge with authorization, split, explicitly discard, or
retain briefly when ambiguity is still meaningful. Source channel does not define
the permanent destination. Review automation, agent, and import subfolders
regularly; they are not archives.
