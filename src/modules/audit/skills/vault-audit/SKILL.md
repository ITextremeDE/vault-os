# Vault audit

Run the OS audit and content audit, then consolidate overlapping findings. When
an OS defect plausibly produces content defects, identify it as the cause and the
content findings as symptoms; prioritize the cause. Keep independent findings
separate.

Return stable overall finding IDs, layer, priority, evidence, cause-symptom logic,
and a recommendation for OS correction, content correction, coordinated vault
correction, or no direct correction. Do not modify files without a later explicit
selection.
