# Projects

A project represents a goal with a recognizable completion state. It belongs to
one registered area and uses the configured project location and template.

Create a project only when an existing project is not the natural home. Maintain
its goal, context, decisions, tasks, and links with small focused updates. Mark
it completed when the outcome is reached, open tasks are resolved or transferred,
and relevant results are documented. Archive it later when active visibility is
no longer useful.
