# Conversation notes

Conversation notes preserve a specific exchange as concise, traceable source
material. They may cover people, organizations, or agent systems. Record the
occasion, relevant content, decisions, and next steps; do not transcribe noise.

Use the configured timestamped filename. Prefer an existing note for the same
conversation. A conversation note documents the exchange, a working note
processes it, and an insight preserves a durable claim.
