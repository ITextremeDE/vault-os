# Archiving

Archive content when active use has ended but historical value remains.
Archiving is a deliberate lifecycle and status decision, not a parking area.

1. Confirm that active relevance or the project goal has ended.
2. Set the configured archived status where applicable.
3. Move the item to the matching archive root without unrelated rewrites.
4. Record the move in the configured content change log.

Do not archive the inbox, journal, or system root. Reactivate archived content
only for genuine renewed use, with an explicit destination and status change.
