# 00 OS

This layer contains the stable operating logic of Vault-OS:

- architecture;
- principles;
- decision logic;
- change principles.

It explains why the system is structured as it is and how it may evolve.
Formal data rules belong to `01 Schema`, concrete instance values to
`02 Registers`, operational behavior to `03 Workflows`, and runtime behavior to
`06 Runtime`.
