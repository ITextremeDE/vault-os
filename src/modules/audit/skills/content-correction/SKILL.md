# Content correction

Require explicit finding IDs or an equivalently precise problem statement. If
several materially different solutions exist, explain the recommended option and
wait for a choice. Then apply only the smallest change that closes the selected
finding: metadata, destination, naming, links, consolidation, journal transfer,
or navigation documentation.

Preserve content and context. Do not delete, mass-edit, change OS rules, or expand
scope silently. Validate each correction against installed rules and report the
authorization basis, files changed, closed findings, and remaining issues.
