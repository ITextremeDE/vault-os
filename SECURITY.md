# Security Policy

## Supported versions

Vault-OS has not published a stable release yet. Security fixes currently
target the latest commit on `main`. After `0.1.0`, this section will identify
the supported release lines.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/ITextremeDE/vault-os/security/advisories/new)
to report suspected vulnerabilities. Do not disclose them in a public issue,
discussion, pull request, or repository comment.

Include the affected Vault-OS version or commit, the relevant command or file,
the expected and observed behavior, the potential impact, and safe reproduction
steps. Do not include credentials or private vault content.

Reports are reviewed privately. A confirmed issue will be fixed and disclosed
in proportion to its impact without publishing private vault data or reporter
information.
